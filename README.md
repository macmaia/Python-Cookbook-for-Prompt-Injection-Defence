# Python Cookbook for Prompt Injection Defence

Runnable Python recipes for defending LLM agents against indirect prompt injection and data exfiltration, with the [catraca](https://github.com/macmaia/catraca) library. Read it at **https://macmaia.github.io/Python-Cookbook-for-Prompt-Injection-Defence/**.

Each chapter is a notebook built by `build.py` from `chNN.py`, which runs every cell and stores its output. To rebuild one: `pip install -r requirements.txt`, then `python build.py ch03.py`. The requirements pin the catraca version the stored outputs came from.
